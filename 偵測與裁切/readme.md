# **偵測與裁切**
本階段透過 YOLOv11 模型，訓練專用於偵測犬隻臉部與眼鼻座標模型，並使用 yolo11m-pose.pt 預訓練模型，校正與裁切出面部區域，並透過色彩填補，補齊旋轉後圖片周邊的無顏色區。考慮到 COCO 資料集中已經有訓練過狗這個類別，預訓練模型應該已具備辨識犬隻邊界框的能力，因此直接沿用 YOLOv11s 作為偵測身體的模型。

**(一) 資料集處理**

實務場景中之政府或民間通報照片，僅提供未經處理之原始犬隻影像，缺乏可用於監督式學習 (Supervised Learning) 的幾何座標標註。為使YOLOv11-pose 模型具備精準偵測犬隻面部關鍵點之先驗能力，本研究導入了 Kaggle 平台上的公開視覺資料集 PetFaceDetection[7]作為模型微調(Fine-tuning) 的訓練基底。該訓練資料集專門針對寵物面部進行了標註，其標註維度契合本系統之需求，包含：

1. 面部邊界框 (Face Bounding Box)：定義犬隻面部之核心特徵區域，濾除不必要之背景雜訊。
2. 核心幾何錨點 (Facial Landmarks)：標註了雙眼 (左眼、右眼) 與鼻子之 2D 像素座標。

進行資料集整理過後，共有 12709 張標示完整之犬隻圖片，其中訓練集有9526 張，驗證集則有 3183 張。本研究利用此資料集對 YOLO11-pose 網路進行遷移學習 (Transfer Learning)，使模型學會跨犬種之頭骨結構與眼鼻相對位置。待模型訓練收斂並具備關鍵點擷取能力後，再將其應用至後續系統之犬隻圖片切割和特徵提取。

**(二) 基於 YOLOv11 之物件偵測與關鍵點擷取**

進行 YOLOv11 模型訓練，以切割出每張影像中的全身與面部邊界框，並依照座標裁切出適當的全身與面部圖像。其中面部特徵具備較高個體辨識度，而身體花色則可作為輔助特徵。本階段的模型訓練包含以下兩個層次：

1. 犬隻面部邊界框和關鍵點提取：採用 YOLOv11m-pose 搭配清理完成的 PetFaceDetection 資料集進行訓練，針對個體定位面部邊界框，並擷取面部關鍵點，定位犬隻之雙眼與鼻子部位。此三個錨點 (Anchors) 構成了犬隻面部的幾何特徵，是後續面部對齊校正之依據，面部邊界框和關鍵點的提取為了效能，於同一個模型中訓練。
2. 犬隻身體邊界框提取：系統直接採用 YOLOv11 官方預訓練權重(COCO 資料集) ，該模型已具備極高的犬隻全身偵測能力，僅需準備測試資料驗證其在本地場景的準確度。不需關鍵點定位的原因為犬隻身體非剛體，且常有不同姿態與動作，若定位四肢並再後續進行強行對齊，會造成犬隻嚴重扭曲，使其型態怪異並且特徵改變。

**(三) 2D 面部幾何校正**

擷取出面部邊界框後，系統會透過核心幾何錨點計算出仿射矩陣，用於將臉部轉正以減少干擾。由於直接旋轉會導致圖片周邊出現黑框（如圖 2），因此旋轉後會做二次裁切，為將照片大小填補至預定的長寬，照片會進行拉伸（如圖 3），然而，這會使遍布比例被破壞，因此我們改用色彩填補的方式補齊（如圖 4）。
