# **身分識別與向量檢索**

　　本部分透過計算使用者上傳的犬隻特徵向量與資料庫內的特徵向量之餘弦相似度，分別針對身體與臉部，各挑出最相近的前十名。
  
**(一)　系統資料庫**
系統資料庫選用 PostgreSQL 配合 pgvector，pgvector 提供 "<=>" 運算子計算兩向量間的餘弦距離，餘閒距離與餘弦相似度的轉換公式為：
$$
Cosine Distance = 1 - Cosine Similarity
$$

**(二) 資料庫之建立**
 選定了資料庫的架構，開始進行建立。為打造更完整之走失犬隻檢索
網，本資料庫整合了四個不同的資料來源：
1. 政府流浪狗資料庫[5]（每日 API 同步）：收容所內待認養之犬隻。
2. 政府飼主報失資料[6]（每日 API 同步）：民眾向政府登記走失之犬隻。
3. 網站使用者拾獲上傳：民眾拍攝之街頭遊蕩犬隻。
4. 網站使用者協尋上傳：飼主自行上傳之愛犬走失紀錄。
 為統一不同格式之資料，資料庫以以下內容作為標籤，涵蓋不同維度：
1. id、gov_animal_id：系統主鍵與政府原始資料庫之唯一識別碼。
2. source_type：標記前述之四大資料來源，作為混合檢索之過濾標籤。
3. status：犬隻目前狀態（如：走失、尋獲、收容中）。
4. metadata：品種、毛色、特徵描述、通報地點與時間戳記。
5. image_url：影像連結。
